# Claude Code: ابنِ أداتك بدون ما تكون مبرمج

**الفكرة:** Claude Code أداة برمجة «وكيلة»: يقرأ ملفات مشروعك، ويعدّل الملفات، ويشغّل الأوامر. أنت تشرح وش تبي بكلامك العادي، وهو:
1. يخطط للطريقة.
2. يكتب الكود في أكثر من ملف.
3. يتأكد إنه يشتغل.

**وين تلقاه؟** (أسهل خيارين لغير المبرمج أول اثنين)
- **تطبيق Claude لسطح المكتب:** سجّل دخولك واضغط تبويب **Code**. ما تحتاج تثبّت أي شي ثاني، ويحتاج اشتراك مدفوع.
- **المتصفح:** claude.ai/code، بدون أي إعداد على جهازك.
- **الطرفية:** أمر تثبيت واحد، ثم تكتب `claude` داخل مجلد مشروعك.
- **محررات البرمجة:** VS Code وJetBrains.

**مثال حرفي:** «عندي ملف مبيعات CSV. أبي أداة تقرأه وتطلع تقرير أسبوعي فيه إجمالي كل منتج ورسم بياني.» Claude Code يخطط، وينشئ الملفات، ويشغّلها. ولو طلع خطأ يتتبّعه لين يلقى السبب ويصلحه، ثم يعيد التشغيل.

**أنت المتحكم:** Claude Code يعرض لك التغيير، ولو استأذنك تختار **Yes** للموافقة. ووضع الصلاحيات (permission mode) هو اللي يحدد وش يقدر يسوي بدون ما يرجع لك، وتبدّله بـ `Shift+Tab`.

**بعدها:**
- **ملف CLAUDE.md:** تحطه في المشروع، وClaude يقرأه أول كل جلسة (تعليماتك ومعاييرك).
- **Routines:** تشغّل Claude على جدول في السحابة، حتى لو جهازك طافي.

**الخطأ الشائع:** طلب عام مثل «صلّح المشكلة». التوثيق ينصح تكون محدد: «صلّح مشكلة تسجيل الدخول اللي تطلّع شاشة فاضية بعد كلمة مرور غلط». وقسّم المهمة الكبيرة لخطوات.
