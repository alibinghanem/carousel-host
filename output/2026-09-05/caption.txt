كل مرة تسمع مصطلح تقني تحس نفسك تايه؟ هالست مصطلحات تغطي ٩٠٪ مما تسمعه — وكل واحد بجملة وحدة بس.

Prompt (الطلب) — النص اللي تكتبه للنموذج. هو المُدخل الوحيد اللي تتحكم فيه.

Token (الوحدة) — أصغر قطعة نص يتعامل معها النموذج. الأسعار والحدود تُحسب فيه، مو بالكلمات.

Context (السياق) — المعلومات اللي أعطيتها في هذي الجلسة. كل محادثة تبدأ بسياق صفري.

Agent (الوكيل) — نظام يستخدم أدوات وينفّذ مهمة كاملة، مو بس يجاوب نص.

API (الواجهة البرمجية) — الباب اللي تتوصل فيه برمجياً بالنموذج بدون واجهة مرئية.

Workflow (سير العمل) — تسلسل خطوات ثابت ومكرر، أساس أي أتمتة.

مثال يربط الكل: طلب عميل يوصل عبر API ← الوكيل يقرأه كـ Prompt ← يستخدم Context من قاعدة بياناتك ← ضمن Workflow يوجّهه للمسؤول الصح. ست كلمات، وصف كامل لنظام حقيقي.

والخطأ الشائع: استخدام «وكيل» و«أتمتة» و«شات بوت» كمترادفات — كل واحد بنية مختلفة تماماً.
