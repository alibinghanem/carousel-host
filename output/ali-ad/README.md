# إعلان «علي التميمي»: لقطة واحدة متواصلة

## المواصفات
- **المدة والصيغة:** 30ث · 1080×1920 · 30fps · 18MB (CRF 20، صوت AAC 256k، بلا clipping).
- **المشروع:** `remotion/studio/src/videos/AliAd/`
  - `camera.ts`: كاميرا ثلاثية الأبعاد بـ CSS، بمسار Hermite ناعم وبلا أي قطع.
  - `index.tsx`: العالم والمحطات.
  - `illus.tsx`: الرسوم التوضيحية (التروس، لوح الدورات وأيقوناتها).
  - `chars.tsx`: الشخصيات الخطية المتحركة (ثوب، وشماغ عنابي، وعقال).
- **الهوية:** سواد منتصف الليل، وزمردي `#1FBF8F`، وذهب شامبانيا `#E8D5A3`.
- **الخطوط:** Aref Ruqaa للاسم (`calt` مطفأ + حشوة للحروف الصاعدة)، وAmiri للنصوص.

| 100–220 | **علي** على منصة بهالة وأشعة، مع الاسم و«حلول الذكاء الاصطناعي والتقنيات المتقدمة» |
| 240–455 | **ثلاث ألواح، كل لوح بشخصية متحركة:** موظف يكتب على لابتوب وهولوغرام مهام · صاحب مشروع يمشي بشنطته وروبوت يستلم الطلبات · طالب يكتب ثم لمبة وقبعة تخرج ومنحنى مهارة |
| 485–555 | **شبكة الوكلاء:** عقد ترتسم، ونبضات بيانات، ونص «أنظمة وكلاء ذكاء اصطناعي… بنيتها لشركات» |
| 555–660 | **لوح الدورات** يرتسم، وقبعة تخرج تنزل على النبض، وثلاث بطاقات بأيقونات متحركة |

| 770–860 | **بطاقة الختام:** الصورة، والاسم، و«تابعني…»، والحسابان، وسطر الشركات |

## الموسيقى
- **المصدر:** ElevenLabs `eleven_music_v2_5` (390 رصيد).
- **الوضع الآلي** مفروض من إعدادات العقدة (`instrumental: true`)، فما احتاجت فحص Scribe.
- **إعادة الترتيب على النبض:** 0–3ث بناء معزّز، والـ drop عند 3ث، وتكرار جملتين بنفس الطور، والخاتمة الطبيعية.
- **الأصل:** الـ flow `E1GCN2WV8IcKqDF6Xekz`.

## الصورة
- **المصدر:** صورة علي الرسمية.
- **القص:** محلياً بـ `@imgly/background-removal-node`، مع إصلاح شفافية الياقة.
- **الملامح:** ما تغيرت، والعملية قص فقط.
