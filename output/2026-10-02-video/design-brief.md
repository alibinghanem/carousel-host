# Design brief — «Claude · ٣ طرق» (فيديو 52ث، 1080×1920)
- **الاستعارة:** لقطة واحدة متواصلة فوق عالم ليلي واحد؛ شريط ضوئي على الأرض يربط خمس «جزر» (منصات)، والكاميرا لا تتوقف أبداً (أقل سرعة 1 وحدة/إطار). بدون بطاقات أو لوحات: كل فكرة رسم متحرك داخل البيئة.
- **الشخصيات والأشياء:** علي بالكاب والنظارة (رسم متجه) يحاور كرة Claude بفقاعات؛ أوراق ملفات تطير بنفسها لمجلدات؛ لابتوب بكود وحشرة (bug) تُسحق بعلامة صح؛ سحابة بساعة تدور وتبعث تقارير لجوال علي وهو نايم ثم تشرق الشمس.
- **الألوان:** خلفية #0A0F1D · المحادثة #F28B5E · Cowork #34D6AE · Code #8F94FF · ذهبي #F2D69B.
- **الخطوط:** Noto Kufi Arabic 900 للعناوين · IBM Plex Sans Arabic للنص · Aref Ruqaa لاسمه · Space Grotesk للأسماء اللاتينية.
- **الكاميرا:** `lib/camera3d` + سرعة مبرمجة (ملف tl.ts): بطيئة عند الجزيرة، سريعة بين الجزر، انحراف جانبي ناعم وميل خفيف.
- **الصوت:** موسيقى ElevenLabs instrumental (٥١.٥ث، drop عند ثانية 4) + مؤثرات. بدون تعليق صوتي.
- **الأصول الحقيقية:** شعار Claude وClaude Code الرسميان (SVG) + صورة علي الأصلية بالنظارة (avatar.png) في الختام.
