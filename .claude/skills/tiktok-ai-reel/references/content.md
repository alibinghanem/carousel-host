# قواعد كتابة المحتوى التدريبي للريلز

## اللهجة والأسلوب

**خليجي احترافي** — لهجة خفيفة مفهومة، بدون تكلّف وبدون عامية ثقيلة.

- ✅ «وش الفرق بينهم؟» · «خلّها تشتغل لحالها» · «هذي أول خطوة»
- ❌ «ما الفارق الجوهري بين هذين المفهومين؟» (فصحى جافة)
- ❌ «يا معشر الشباب تكفون» (عامية زائدة)

المصطلحات التقنية المستقرة تُترك كما هي: Prompt · Agent · Webhook · API · Workflow.
اشرحها بالعربي أول مرة تذكرها.

## قاعدة الهوك — أول ٣ ثوانٍ

الهوك يقرر ٩٠٪ من المشاهدات. اختر واحداً:

| النوع | مثال |
|---|---|
| رقم صادم | «٧٣٪ من شغلك الإداري تقدر تأتمته» |
| خطأ شائع | «تكتب البرومبت غلط — وهذا السبب» |
| سؤال مباشر | «ليش مخرجاتك تطلع عامة دايماً؟» |
| وعد محدد | «في ١٠ دقايق بتسوي أول أتمتة لك» |
| مفارقة | «الأداة مو المشكلة… أنت المشكلة» |

**ممنوع:** «اليوم راح نتكلم عن…» — أضعف بداية ممكنة.

## بنية الدرس (٨–١٠ مشاهد · ٤٠–٥٠ ثانية)

1. **hook** — الوعد أو الصدمة (٣.٥ث)
2. **مشهد المشكلة** — ليش الموضوع يهمّه أصلاً (٤.٥ث)
3. **التعريف/المفهوم** — رسمة توضيحية تشرح الفكرة (٥–٦ث)
4. **التفصيل ١** — الخطوات أو المكوّنات (٦ث)
5. **التفصيل ٢** — رقم، مقارنة، أو مثال واقعي (٥ث)
6. **التطبيق العملي** — «سوّ كذا اليوم» بمثال حرفي (٥.٥ث)
7. **الخطأ الشائع / التحذير** — وش يوقعهم (٤.٥ث)
8. **الخلاصة** — الفكرة في جملة تنحفظ (٤ث)
9. **cta** — سؤال + متابعة + الصورة الشخصية (٤.٥ث)

**كل مشهد لازم يعطي معلومة جديدة.** لا مشهد حشو.

## المحتوى التدريبي = تفصيل حقيقي

الفرق بين ريل عادي وريل تدريبي هو **التحديد**:

- ❌ «استخدم الذكاء الاصطناعي في التقارير»
- ✅ «اربط ملف المبيعات → اطلب ملخّص أسبوعي بثلاث نقاط → جدوله كل أحد ٨ صباحاً»

كل نصيحة لازم تكون **قابلة للتنفيذ اليوم**: أداة، خطوة، أو صيغة حرفية.

## اختيار الرسمة المناسبة

| المحتوى | الرسمة |
|---|---|
| تسلسل خطوات أو عملية | `flow` |
| نسبة أو إحصائية | `ring` |
| مقارنة أرقام / قبل وبعد | `bars` |
| نظام له مركز وأطراف | `hub` |
| مستويات أو مراحل | `layers` |
| ٤–٦ عناصر متوازية | `icons` |
| خيارين متقابلين | `compare` |

**استخدم ٣–٤ رسومات مختلفة في الريل الواحد** — التنويع يمنع الملل البصري.

## حدود النصوص (تجاوزها يكسر التصميم)

| الحقل | الحد |
|---|---|
| `title` في hook/cta | ≤ ٧ كلمات |
| `title` في مشاهد الرسومات | ≤ ٦ كلمات |
| `body` | ≤ ٣٠ كلمة |
| `sub` | ≤ ١٢ كلمة |
| `label` في flow/icons | ≤ ٤ كلمات |
| `note` | ≤ ٥ كلمات |
| نص عقدة `hub` | ≤ كلمتين |

- ضع `*نجمتين*` حول الكلمة المهمة لتلوينها بلون التمييز.
- الأرقام دائماً **لاتينية**: `73%` `11` `1,200` — أوضح بصرياً وأأمن في الترتيب.

## الكابشن (تيك توك)

```
[الهوك بصيغة ثانية — سطر واحد]

[٣–٤ أسطر تفصيل يضيف قيمة على الفيديو، مو تكرار له]

[سؤال للتعليقات]

#الذكاء_الاصطناعي #الأتمتة #تعلم_الذكاء_الاصطناعي #تقنية
#ai #automation #السعودية #ريادة_الأعمال
```

- ٦–٩ هاشتاقات: مزيج عربي وإنجليزي، عام وخاص.
- أول سطرين بس يظهرون قبل «المزيد» — خلّهم الأقوى.
- لا تكرر نص الفيديو حرفياً في الكابشن.

## الصوت

الفيديو يُنتَج **بدون موسيقى** عمداً — تيك توك يفضّل الأصوات الرائجة من مكتبته،
وإضافتها داخل التطبيق ترفع الوصول. نبّه المستخدم يضيف صوتاً رائجاً بمستوى منخفض.
