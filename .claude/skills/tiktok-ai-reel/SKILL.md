# كاروسيل تيك توك — محتوى تدريبي بالذكاء الاصطناعي

ينتج كل تشغيل: **شرائح صور عمودية** + **درس تدريبي مكتوب** + **كابشن جاهز للنشر**.

> **لماذا كاروسيل وليس فيديو؟** المحتوى التدريبي الكثيف يحتاج قارئاً يتحكّم
> بسرعته — يسحب متى ما خلص ويرجع لو ما فهم. الفيديو يفرض إيقاعاً ثابتاً، وتيك
> توك يقارنه بفيديوهات فيها وجوه وأصوات فيخسر. الكاروسيل يُقارَن بمنشورات صور،
> والشريحة الأولى ظاهرة كاملة من اللحظة صفر. هذا مثبت على هذا الحساب تحديداً.

## سير العمل

### ١ · اختر موضوع اليوم

```bash
python3 .claude/skills/tiktok-ai-reel/pick_topic.py
```

يرجّع موضوع اليوم مع **الستايل واللون المخصّصين له** — لا تغيّرهما، هما اللي
يضمنون إن كل موضوع يطلع بتصميم مختلف عن اللي قبله. السكربت يسجّل الموضوع
تلقائياً فلا يتكرر قبل ٦٠ يوم.

> لو طلب المستخدم موضوعاً محدداً، اكتبه بنفسك واختر ستايلاً ولوناً ما استُخدما
> في آخر ٥ أيام (شوف `state/used.json`).

### ٢ · جهّز مجلد اليوم

```bash
D=output/$(date +%F) && mkdir -p $D
```

### ٣ · اكتب الدرس التدريبي أولاً

**اقرأ `references/content.md` قبل الكتابة** — فيه قواعد اللهجة والهوك والبنية.

اكتب `$D/lesson.md`: الدرس كاملاً كنص تدريبي مفصّل (٢٥٠–٤٠٠ كلمة) — الفكرة،
التفصيل، مثال حرفي قابل للتطبيق، والخطأ الشائع. هذا هو المرجع اللي تشتق منه
المشاهد، وهو أيضاً مادة يستفيد منها المستخدم لوحدها.

**التفصيل مطلوب:** كل نصيحة لازم تكون قابلة للتنفيذ اليوم — أداة، خطوة، أو صيغة
حرفية. لا تكتب «استخدم الذكاء الاصطناعي في التقارير»، اكتب الخطوات الثلاث بالضبط.

### ٤ · حوّل الدرس إلى شرائح

اكتب `$D/slides.json`:

```json
{
  "style": "<من pick_topic>",
  "accent": "<من pick_topic>",
  "handle": "@ali_altamimy_tech",
  "slides": [ ... ]
}
```

**بنية السبع شرائح:**

| # | النوع | الدور |
|---|---|---|
| ١ | `hook` | الغلاف — يقرر إن كان أحد بيسحب أصلاً. رقم أو مفارقة |
| ٢ | نقطة/رسمة | المشكلة أو التعريف |
| ٣–٥ | رسومات | التفصيل — رسمة مختلفة في كل شريحة |
| ٦ | `tip` | الخلاصة أو الخطأ الشائع |
| ٧ | `cta` | الدعوة + صورة علي |

**استخدم ٣–٤ أنواع رسومات مختلفة.** الأنواع المتاحة:

| النوع | الحقول |
|---|---|
| `hook` | `kicker` `big` `title` `sub` |
| `point` | `icon` `n` `title` `body` |
| `stat` | `big` `title` `body` |
| `tip` | `icon` `title` `body` |
| `steps` | `title` `items[]` |
| `quote` | `text` `author` |
| `compare` | `title` `bad{label,text}` `good{label,text}` |
| `flow` | `title` `nodes[{icon,label,note}]` `body` — مسار عملية (٣–٤ عقد) |
| `ring` | `title` `pct` `label` `body` — نسبة مئوية متحركة |
| `bars` | `title` `unit` `items[{label,v,hi}]` `body` — مقارنة أرقام |
| `hub` | `title` `center` `nodes[{icon,label}]` `body` — نظام بمركز وأطراف (٤–٦) |
| `layers` | `title` `items[{label,note}]` `body` — مراحل أو مستويات |
| `icons` | `title` `items[{icon,label,note}]` `body` — ٤–٦ عناصر متوازية |
| `cta` | `kicker` `title` `body` `name` `handle` — **يضيف صورة علي تلقائياً** |

حقل `dur` غير مستخدم في الكاروسيل — احذفه.

**الأيقونات المتاحة:** `bolt gear bot doc mail calendar chart chip cloud clock check
users search sparkle database link shield target rocket lock filter refresh message
code money warn eye`

**آخر شريحة لازم تكون `cta`** — فيها صورة علي بخلفية مصممة تلقائياً.

**الشريحة الأولى هي الغلاف** — تظهر في الخلاصة قبل أي سحب، فاجعلها أقوى شريحة.
تلميح «اسحب» يُضاف عليها تلقائياً.

**النص أطول قليلاً من الفيديو:** القارئ يتحكّم بسرعته، فـ `body` يقبل حتى
٤٠ كلمة بدل ٣٠. لكن `title` يظل ≤ ٧ كلمات.

### ٥ · افحص التصميم بصرياً — خطوة إلزامية

```bash
python3 .claude/skills/tiktok-ai-reel/render_carousel.py $D/slides.json $D
```

**اقرأ كل شريحة بأداة Read وافحصها فعلياً.** تأكد من:

- الحروف العربية **متصلة** وغير مقلوبة
- لا نص مقصوص أو خارج الإطار أو متداخل مع رسمة
- النص داخل المنطقة الآمنة (تيك توك يغطي أعلى ٢٤٠px وأسفل ٤٥٠px)
- التباين واضح والرسومات مفهومة

لو طلع نص طويل يكسر التخطيط — اختصره وأعد الفحص.

المخرجات: `$D/slide_01.jpg` … `$D/slide_07.jpg` (+ `cover.jpg` نسخة من الأولى).
يستغرق أقل من دقيقة — أعد التوليد بحرية لو احتجت تعديل نص.

### ٧ · اكتب الكابشن

`$D/caption.txt` — حسب قواعد `references/content.md` (هوك مختلف عن الفيديو،
تفصيل يضيف قيمة، سؤال، ٦–٩ هاشتاقات).

### ٨ · سلّم

1. `SendUserFile` لكل ملفات `slide_*.jpg` **بالترتيب** دفعة واحدة
2. **اكتب الكابشن كاملاً كنص في المحادثة** (لا كملف فقط) عشان ينسخه فوراً
3. اذكر عنوان الدرس ورقم اليوم في الدورة
4. ذكّره يرفعها في **وضع الصور (Photo mode)** على تيك توك بنفس الترتيب،
   ويضيف صوتاً رائجاً من المكتبة

### ٩ · احفظ في المستودع

```bash
git add -A && git commit -m "ريلز <التاريخ>: <عنوان الموضوع>" \
  && git push -u origin claude/daily-tiktok-reels-task-eh6n4x
```

الشرائح صغيرة (~١٤٠ KB) فتُحفظ كاملة في المستودع مع الدرس والكابشن.

## ملاحظات تقنية

- **لا تستخدم PIL لرسم العربية** — المولّد يستخدم Chromium اللي يتولّى التشكيل
  والاتجاه تلقائياً وبشكل صحيح.
- الاعتماديات تُثبَّت مرة واحدة: `pip install playwright imageio-ffmpeg --break-system-packages`
  (Chromium و ffmpeg موجودان مسبقاً في البيئة).
- **لماذا لا فيديو؟** جُرّب ١١ يوماً وأداؤه أضعف من الكاروسيل على هذا الحساب.
  `render_reel.py` باقٍ في المجلد ويشتغل، لكنه ليس المسار اليومي.
